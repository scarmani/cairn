## Additive analysis interface

Build on `lab_evidence`, `lab_spec`, `lab_record` and `lab_symmetry`. Do not modify
their source or any engine/server/browser/search implementation in this unit.
Add focused modules for evidence assembly, mechanical record analysis, and an
offline report CLI. Use standard-library JSON, hashing, SVG and HTML only.

The record analyzer validates and mechanically replays only the supplied recorded
actions. Because the existing replay API returns a receipt rather than frames,
one additional explicit replay may obtain before/after frames. Report both passes
honestly. Existing legal-action enumeration performed by unchanged mechanical
replay validation remains required; do not bypass it. Never expand or evaluate
alternatives for analysis, choose new moves or invoke an opponent, proof producer,
checker, MCTS, training service or budget writer.

For each trace retain rule/revision, board size, neutral seats and post-pie colors,
full action/orientation, captures split between original points and hubs, and
separate rules-action, placement and construction counters. A planted action is
one action contributing to both placement and construction counts. Contact is
measured against the actual pre-placement graph; for planted construction use
the newly activated spokes and pre-action stone colors, explicitly stated.

Heat maps are raw executed-point counts, stratified by ruleset, size and source
kind. Construction sites use their projected face centers. Friendly and enemy
contact count placements adjacent to at least one respective stone, not the
number of incident edges. Empty data stays an empty observation, not a zero
rating. Admitted-match heat maps remain unmeasured.

The motif atlas groups recorded frames using the existing conservative D6
spatial/phase key, with deterministic canonical representatives. This key ignores
some history and is never a full-state cache key, strategic equivalence, proof,
or evidence of independent repeated discovery. Link every member back to its
trace and action index. Render actual edges, original/scoring vertices, neutral
zero-point hubs, stones, cells and orientations. Successful capture and reopened
hub examples are mechanical demonstrations, not best-move labels.
